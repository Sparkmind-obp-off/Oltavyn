# Operating Workflow — Internal Affiliate Pilot

## Workflow A: product research

1. Create or select an OLTAVYN workspace for the affiliate operation.
2. Record the research question, audience, niche, and permitted sources.
3. Add product candidates manually or from an owner-provided export.
4. For each candidate, save a product URL and evidence records with capture date, method, excerpt, interpretation, and limitations.
5. Keep unavailable commission, sold count, rating, or price fields NULL.
6. Score each candidate using the current rubric; explain every score.
7. Shortlist only products with inspectable evidence and a feasible faceless content angle.
8. Reject or archive unsuitable products with a reason.

## Workflow B: content preparation

1. Select a shortlisted product.
2. Create an opportunity that states the audience problem and why this product may solve it.
3. Link evidence as supports, challenges, or context.
4. Draft a content brief: target audience, problem, promise, angle, hook, proof, caveats, CTA, and disclosure.
5. Create a faceless video script and storyboard using the existing Content Studio.
6. Map factual claims to evidence. Mark unsupported claims as needing verification.
7. Review asset version, claim map, rights of every visual/audio asset, affiliate disclosure, and destination.
8. Approve the exact version and channel destination.

## Workflow C: publishing and observation

1. Generate/copy the affiliate link through the official affiliate interface manually.
2. Attach it to the experiment record; do not scrape or automate account actions.
3. Publish manually on the approved channel.
4. Record the public publication URL and timestamp.
5. Record available metrics with an observation window and origin.
6. If a metric is unavailable, record `not_yet_available` or `not_collected`, not zero.
7. Use the Learning Summary to decide whether to repeat, revise, or stop.

## Minimum experiment record

- Product ID and channel ID
- Approved content version and approval ID
- Hypothesis and intended audience
- Publication URL and timestamp
- Metric name, numeric value if observed, unit, observation window, origin, and source reference
- Notes about limitations or attribution uncertainty

## Initial manual content formats

1. Problem → solution explanation
2. Product feature walkthrough using authorized assets
3. Comparison / buying guide with explicit criteria
4. Product shortlist / curated finds
5. Common mistake → selection checklist

Never simulate hands-on use, unboxings, or testimonials. If using seller-provided footage, ensure reuse is permitted and do not imply it is original footage.
